# 0–90 Календарь — обои «недели жизни» для iPhone 13

Аналог сервиса life.gleb.solutions, упрощённый под одну задачу:

- **Только iPhone 13** — обои 1170×2532, без выбора модели;
- **Только светло-голубой фон** (`#AEE1F9`), без выбора темы;
- Недели жизни от 0 до 90 лет: сетка **52 × 90 = 4680 точек** (строка = год, точка = неделя);
- Тёмные точки — прожитые недели, белые — оставшиеся;
- **Текущая неделя отмечена вашим логотипом** (`assets/logo.png`) вместо обычного кружка;
- Внизу — процент пути (`29.8% to 90`) и фраза «Действуй сейчас / У тебя ещё есть время», как в оригинале.

## Как это работает

```
iPhone («Команды», автоматизация по времени)
        │  каждый день в 7:00: «Получить содержимое URL»
        ▼
GET https://ваш-сервер/api/cal?birth=2000-01-01
        │  сервер считает недели НА СЕГОДНЯ и рисует PNG
        ▼
«Установить фото как обои» → экран блокировки обновился
```

Дата рождения зашита прямо в ссылку, поэтому никакой регистрации и базы данных не нужно.
Автоматизация запускается ежедневно, а логотип сдвигается на следующую точку в день,
когда начинается новая неделя вашей жизни (каждые 7 дней от даты рождения).

## Запуск локально

Нужен Python 3.10+.

```bash
pip install -r requirements.txt   # единственная зависимость — Pillow
python app.py                     # http://localhost:8000
```

Откройте страницу, введите дату рождения — появятся превью, статистика и ссылка вида:

```
http://localhost:8000/api/cal?birth=2000-01-01
```

Ссылка совместима и с «длинным» форматом оригинала
(`?type=life&theme=black&lang=ru&birth=...&lifespan=90&w=...&h=...&fs=60`) —
все параметры, кроме `birth`, принимаются и игнорируются.

Только картинка без сервера (например, поставить обои вручную один раз):

```bash
python wallpaper.py --birth 2000-01-01 --out wallpaper.png
```

## ⚠️ Главное: сервер должен быть доступен из интернета

iPhone скачивает обои по ссылке сам, без вашего компьютера. Если сервер крутится
только на домашнем ПК, ссылка `localhost` с телефона не откроется. Варианты:

| Способ | Что сделать |
|---|---|
| **Render.com** (бесплатный тариф) | Залейте содержимое папки проекта в корень GitHub-репозитория → на Render: New → Blueprint (или Web Service) → этот репозиторий. В проекте уже есть `render.yaml` с `plan: free`, командами сборки/запуска и часовым поясом. Получите адрес вида `https://life-cal-090.onrender.com`. Нюанс: бесплатный Web Service засыпает после 15 минут без запросов и просыпается около минуты. Для надёжности сделайте в «Командах» отдельную автоматизацию-пробуждение за 5 минут до основной: она просто открывает `/api/health`, а основная после этого скачивает обои уже с проснувшегося сервера. |
| **Railway / Fly.io / любой VPS** | Команда запуска: `python app.py`, порт берётся из переменной `PORT` автоматически. |
| **Быстрый тест дома** | Запустите `python app.py` на компьютере и откройте с телефона `http://IP-компьютера:8000` (телефон и ПК в одном Wi-Fi). Для проверки хватит, для постоянной автоматизации — нет. |

Итоговая ссылка для «Команд» будет вида:

```
https://ваш-сервер/api/cal?birth=2000-01-01
```

## Настройка на iPhone (приложение «Команды»)

1. Открой **«Команды»** → вкладка **«Автоматизация»** → **+** → **«Время суток»**.
2. Время — любое (например, 7:00), Повтор — **По дням**, Запуск — **Немедленный запуск** → Далее → Новая автоматизация.
3. Добавь действие **«Получить содержимое URL»**, в поле URL вставь ссылку выше со **своей** датой рождения.
4. Добавь действие **«Установить фото как обои»**: Изображение — *Содержимое URL*, Экран — *Экран блокировки*. В настройках действия (стрелочка) отключи **«Показать окно просмотра»** и **«Обрезать до темы»**.
5. **Готово.** Для проверки: открой созданную автоматизацию и нажми «Выполнить» — обои сразу сменятся.

Подробная инструкция с картинками-подсказками есть и на самой веб-странице приложения.

## Что где лежит

```
app.py            сервер: страница + API /api/cal (без фреймворков, только stdlib)
wallpaper.py      вся логика и отрисовка обоев (+ CLI-режим)
static/index.html веб-страница: форма, превью телефона, ссылка, инструкция
assets/logo.png   ваш логотип — маркер текущей недели (замените файл, чтобы сменить)
assets/fonts/     шрифты DejaVu Sans (кириллица), чтобы подписи рисовались везде одинаково
examples/         пример готовых обоев для даты 2000-01-01
render.yaml       готовый конфиг для деплоя на Render
Procfile          команда запуска для PaaS-хостингов
```

## Если захочется поменять

Все константы — в начале `wallpaper.py`:

- `BG_COLOR` — цвет фона (сейчас светло-голубой `#AEE1F9`);
- `PAST_COLOR` / `FUTURE_COLOR` — цвета прожитых/оставшихся недель;
- `MARKER_SIZE` — размер логотипа текущей недели в пикселях (сейчас 12 px — ровно как диаметр обычной точки-недели; текст логотипа в таком размере заведомо не читается, так задумано);
- `WIDTH, HEIGHT` — если позже понадобится другая модель iPhone;
- фраза и формат процента — в конце `render_wallpaper()`.

Часовой пояс, по которому сервер определяет «сегодня», задаётся переменной
окружения `TZ_NAME` (по умолчанию `Europe/Moscow`), порт — переменной `PORT` (по умолчанию 8000).
