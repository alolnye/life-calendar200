Автообновление обоев

Настрой автоматизацию один раз — телефон сам будет скачивать обои по ссылке выше. Картинка каждый день запрашивается заново, а логотип сдвигается на следующую точку, когда начинается новая неделя вашей жизни.

1. Открой приложение «Команды»

Это встроенное приложение Apple. Если не можешь найти — потяни вниз на домашнем экране и напиши Команды.

📱Найди приложение «Команды» (Shortcuts)

2. Перейди в «Автоматизация»

Внизу экрана есть вкладка Автоматизация — нажми на неё.

3. Создай новую автоматизацию

Нажми + в правом верхнем углу, затем выбери Время суток.

4. Настрой расписание

🕐Время: любое удобное (например, 7:00)
↩️Повтор: По дням
▶️Запуск: Немедленный запуск

Нажми Далее, затем Новая автоматизация (пустая).

5. Добавь действие загрузки

В поиске введи Получить содержимое URL и добавь действие. В поле URL вставь ссылку для автоматизации с этой страницы (блок выше).

6. Добавь установку обоев

В поиске напиши обои и выбери Установить фото как обои.

🖼️Изображение: Содержимое URL (подставится автоматически)
🔒Экран: выбери Экран блокировки

Нажми на стрелочку в кружке в этом действии и отключи:

👁️Показать окно просмотра — отключи
✂️Обрезать до темы — отключи

7. Сохрани

Нажми Готово. Важно: запуск должен стоять «Немедленный запуск», а не «После подтверждения» — иначе телефон будет каждый день спрашивать разрешение.

💡 Совет Чтобы проверить, что всё работает, — в списке автоматизаций нажми на созданную и выбери Выполнить. Обои должны сразу обновиться.
Важно про ссылку: телефон скачивает обои из интернета, поэтому сервер должен быть постоянно доступен по публичному адресу (https). Если приложение запущено только на вашем компьютере, автоматизация сработает, лишь пока компьютер включён и находится в той же сети. Как бесплатно выложить сервер в интернет — см. файл README.md в проекте.
